# Auto-Scaling & Monitoring Dashboard
## Overview
Simulates cloud auto-scaling: servers are added or removed automatically based on CPU utilisation as traffic changes.
## Cloud concepts covered
Elasticity, horizontal scaling, scaling policies/thresholds, cooldown, monitoring (CloudWatch-style).
## Features
Traffic slider, editable scale-out/in thresholds, 1-8 servers, live CPU graph (Canvas), last-action log.
## How to run
Unzip, open `index.html`, drag the traffic slider.
## Files
`index.html` | `style.css` | `script.js`
